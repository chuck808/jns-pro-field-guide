    At the track

    Quick Start

    From power-on to a recorded run in six steps.

    1
    Power on

    Turn on the controller and the devices supplied with your kit.

    2
    Open Gate Pro

    Use the ANO control to highlight Gate Pro and press to select.

    3
    Reset

    If RESET is shown, select it to prepare the enabled external devices.

    4
    Start

    Get into position and begin the start sequence when you are ready.

    5
    Ride

    React to the sequence and ride your run normally.

    6
    Review

    Check the Finish result, then continue or finish the session.

    ●
    ANO controlRotate = move · Press = select/edit · Left = back/cancel · Hold only where the screen tells you to

    The field-test system

    Three units. One training flow.

    The current test kit combines the JNS Pro controller with JNS Lights and JNS Timer. A physical JNS Gate is part of the wider system but is not included in this particular field-test kit.

    CONTROL

    JNS Pro Controller

    Runs Gate Pro, records the onboard motion data, manages settings and displays the result.

    START

    JNS Lights

    Provides the external BMX start-light sequence used during the run setup.

    FINISH

    JNS Timer

    Provides the external finish reference. The production-facing display is red and sits behind a clear protective cover.

    The Fusion 360 renders show the real enclosure geometry. The Timer tripod alignment in the render is only an assembly-view limitation, not an intended lean in the finished unit.
